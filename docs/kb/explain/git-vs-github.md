# What is the difference between Git and GitHub?

Short version: **Git is the tool. GitHub is the website.**

## Git

Git is a program on your computer. It tracks changes to your files — like "save points" in a video game. You can commit (save), undo, and branch (try things) all without the internet.

## GitHub

GitHub is a website that **hosts** your Git projects online. It's where your code lives so other people can see it, and so you can access it from anywhere. Think of it like Google Drive, but for code.

## The relationship

- Git works **offline**, on your computer.
- GitHub needs the **internet** — it's a place to store and share.
- You use Git to manage your code. You use GitHub to **push** (upload) it so it's backed up and shareable.

## The common confusion

"I have to be online to commit." **No.** Commits are local — Git doesn't need the internet. Only push and pull (sending to / getting from GitHub) need a connection.

## The one-liner

**Git = the save system. GitHub = the cloud where saves are stored.**
