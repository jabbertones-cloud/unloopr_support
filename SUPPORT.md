# Support

## Public support
Use GitHub Issues for questions and problems that can be discussed without secrets. Search the [troubleshooting index](docs/troubleshooting.md), [FAQ](docs/faq/faq.md), and [glossary](https://unloopr.com/terms) first.

Pick the **"I'm stuck"** template and describe what's happening in your own words. We answer in plain words too.

## Scan-based help
If your question is about a specific Unloopr scan, include the repo name and the fix title. Don't paste your full report — we can look it up.

## Private support
If your issue involves a secret that's already exposed, follow the [API key leak guide](docs/faq/faq.md#i-pushed-my-api-key-to-github--what-now) first, then contact us privately. Never post the secret itself in an issue.

## Security
Do not open a public issue for a vulnerability. Follow SECURITY.md.
