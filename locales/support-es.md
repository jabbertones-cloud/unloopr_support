## ¿Qué hace Unloopr?

Unloopr lee el historial de tu código y te enseña sobre errores antes de que los cometas. Analiza tu repositorio y mira tus 3 correcciones más importantes gratis.

## ¿Mi código está seguro?

Sí. Unloopr lee tu código para enseñarte. Nunca comparte tu código con nadie.

## ¿Qué recibo gratis?

Cada análisis de repositorio muestra tus 3 correcciones más importantes gratis. Para el informe completo, elige un plan.

## No sé qué es un commit. ¿Unloopr es para mí?

Sí. Unloopr está hecha para ti. Explica todo en palabras simples, sin jerga.
