# Contributing to Unloopr Support

This is the public place to help people understand Unloopr scans, MCP connections and code-coaching failures. Please search [open and closed issues](https://github.com/jabbertones-cloud/unloopr_support/issues?q=is%3Aissue) and read [AGENTS.md](AGENTS.md) first.

## Open a useful report

Describe what you tried, what happened and what you expected in plain words. Include the affected feature, client/version if known and safe steps that reproduce the problem. Choose the [Bug report or I'm stuck form](https://github.com/jabbertones-cloud/unloopr_support/issues/new/choose).

Do not share private repository contents, scan reports, API keys, auth tokens, private customer details or credentials. For a vulnerability, follow [SECURITY.md](SECURITY.md) and do not create a public issue.

## Agent contribution

Agents should use the official [GitHub MCP issue tools](AGENT-GITHUB-ISSUES.md) with the requesting user's authorization. Search for duplicate issues, distinguish observed errors from guesses, and only post new issues or responses when asked. Do not manufacture test tickets or promise a fix before verification.

Public documentation and coaching notes should explain how to reproduce and verify a solution without revealing anyone's private code.
