# Support

**Public questions and bugs:** Search [Unloopr support issues](https://github.com/jabbertones-cloud/unloopr_support/issues) and [troubleshooting](docs/troubleshooting.md) first, then file a sanitized issue through [the issue form](https://github.com/jabbertones-cloud/unloopr_support/issues/new/choose).

**Private account, billing, or personal information:** Use [Unloopr private support](https://unloopr.com/support). Do not post access tokens, private repositories, customer information, payment details or raw scan output that includes secrets in a public ticket.

**Feature availability:** Read [the verified product status](docs/current-product.md). Do not promise live billing, a published ChatGPT directory app, or automatic fixes. A public scan may return zero findings.

**Security vulnerabilities:** Follow [SECURITY.md](SECURITY.md). Do not open a public vulnerability report.
